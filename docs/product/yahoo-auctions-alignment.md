# Yahoo!オークションとの仕様比較

- 状態: [ADR-0007](../adr/0007-align-with-yahoo-auctions.md) の根拠資料
- 確認日: **2026-11-06**（Yahoo! JAPAN ヘルプセンターの公式ヘルプを読んで確認）
- 注意: Yahoo!オークションの仕様は変わることがある。実装前に、下の出典で再確認すること。

> Yahoo!オークションは参考にする仕様の出典として名前を挙げているだけで、商標・ロゴ・画面デザイン・文章・画像は使わない（AGENTS.md）。

## 比較表

| 項目 | Yahoo!オークション（2026-11-06 確認） | めぐる市（ADR-0007 後） | 出典 |
|---|---|---|---|
| 入札単位 | 現在の価格が 1円〜1,000円未満：10円／1,000円〜5,000円未満：100円／5,000円〜1万円未満：250円／1万円〜5万円未満：500円／5万円〜：1,000円 | 同じ（ADR-0004 の独自表から変更） | [入札単位][unit] |
| 入札額の刻み | 最低入札額以上なら1円単位 | 同じ | [入札単位][unit] |
| 最低入札額 | 入札者なし：現在の価格（＝開始価格）／入札者あり：現在の価格＋入札単位 | 同じ | [入札のしくみ][bid] |
| 自動入札 | すべての入札が自動入札。予算の最高額で入札し、他者が入札すると自動で再入札する | 同じ（MVP の対象外から変更） | [入札のしくみ][bid] |
| 現在の価格の決まり方 | 例：相手の最高額700円に500円で入札 → 相手が510円で最高額入札者。715円で入札 → 自分が710円で最高額入札者 | 同じ | [入札のしくみ][bid] |
| 最高入札額の公開 | 自分の入札額が相手の最高入札額を上回るまで、相手の最高入札額は分からない | 同じ（本人以外に表示しない） | [入札のしくみ][bid] |
| 同額の最高入札額 | ヘルプに記載なし | **独自に決定**：先に受付確定した入札者を優先 | — |
| 即決価格 | 即決価格以上で入札すると、その時点で落札。自動入札は働かない | 同じ（MVP の対象外から変更） | [入札のしくみ][bid]、[販売形式と価格][price] |
| 自動延長 | 出品者のオプション。終了前5分の間に価格が上がると5分延長し、延長後も繰り返す。価格が上がらなければ延長しない | 同じ。**既定値は「あり」**（独自に決定） | [オプション設定][option]、[終了日時][end] |
| 早期終了 | 出品者が終了日時より前に締め切れる | 同じ | [オプション設定][option] の関連ページ（詳細ページは未読） |
| 終了日時 | 午前出品：13時間〜7日間（1時間単位）、午後出品：12時間〜7日11時間、アプリ：13時間〜7日11時間 | 13時間〜7日11時間、1時間単位（アプリの範囲に統一） | [終了日時][end] |
| 販売形式 | オークション形式／フリマ（定額）形式 | オークション形式のみ（定額は将来検討） | [販売形式と価格][price] |
| 入札者の制限 | 出品者のオプション。総合評価がマイナスの人、悪い評価が多い人、SMS 認証をしていない人などを制限できる | 将来検討（評価機能が前提） | [オプション設定][option] |
| 自動再出品・自動値下げ | 落札されずに終了したとき、指定回数まで自動で再出品できる | 将来検討 | [オプション設定][option] |
| 有料オプション | 注目のオークション（1日22円〜）など | 採用しない | [オプション設定][option] |
| 最低落札価格 | 2019年9月30日に設定が終了している | 採用しない | [出品に関連する一部の有料オプションの終了][notice]（検索結果の抜粋で確認。ページ本文は未読） |
| 出品オプションの利用条件 | 自動延長などのオプションは LYP プレミアム会員が出品するときに設定できる | 会員なら誰でも設定できる（課金なし） | [オプション設定][option] |
