# ADR-0001: 最初のレビュー可能な成果物を静的フロントエンドにする

- 状態: 採用（プロトタイプの実装範囲に限る）
- 日付: 2026-10-10
- 背景: リポジトリにアプリケーションコード、依存定義、DBスキーマ、既存ADRがなく、技術スタックは未選定。AGENTS.mdは決済・認証・運用などの重要な事項を未決としている。

## 決定

新規依存を導入せず、HTML/CSS/JavaScriptの静的フロントエンドで、日本語のオークション操作プロトタイプを作成する。サンプル出品を表示し、検索、カテゴリ、並び替え、詳細、ウォッチ、整数JPYのデモ入札、出品入力を確認できる。ブラウザ内で作成するウォッチ・出品・入札履歴はlocalStorageに保存する。

この決定は本番システムの技術選定ではない。認証はデモ案内だけとし、入札・終了判定・取引確定・通知・決済はサーバー処理として実装したと扱わない。自動延長、同額入札、手数料、KYC、禁止商品、キャンセル・返金等の未決仕様は決めない。

## 理由

- 既存の採用技術を推測せず、すぐに画面と主要なユーザーフローをレビューできる。
- 静的ファイルのみで起動でき、新規パッケージや秘密情報を必要としない。
- UIのデモ操作と本番の認証・金銭取引を誤認させないよう制約を画面とREADMEに明示できる。

## 影響と次の判断

複数ユーザーの共有、認証・認可、DB永続化、競合制御、メール、画像保存、管理・監査、実際の注文・決済には対応しない。次フェーズでは要件と運用責任者を確認し、認証、DB、バックエンド、ホスティングを別ADRで選定する。本番相当の入札実装時には同時入札・境界時刻・冪等性・終了との競合の統合テストが必要。

## 復旧

データベース変更や外部サービス設定はない。プロトタイプのブラウザ内データは、利用者がサイトデータを削除することで消去できる。
