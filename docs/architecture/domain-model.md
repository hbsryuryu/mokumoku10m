# ドメインモデル

> 出典: AGENTS.md 4章。ER 図・属性の詳細は今後追記する。

| エンティティ | 概要 |
|---|---|
| `User` | 公開プロフィール、ステータス、権限 |
| `AuthIdentity` | 認証 ID・認証プロバイダー |
| `Listing` | 出品商品と公開状態 |
| `ListingImage` | 画像の参照、表示順 |
| `Category` | 商品カテゴリ |
| `Auction` | 開始時刻、終了時刻、開始価格、最小入札増分、状態 |
| `Bid` | 入札者、入札金額、入札日時、受付結果 |
| `WatchlistItem` | ユーザーと出品の対応 |
| `Order` | 落札後の取引（購入者、出品者、確定金額、進行状態） |
| `Payment` | 外部決済の識別子、決済状態、金額 |
| `Shipment` | 発送方法、追跡情報、発送状態 |
| `Notification` | 通知先、種類、既読状態 |
| `Report` | 通報対象、理由、審査結果 |
| `AuditLog` | 管理操作・重要な状態変化の記録 |

## 共通ルール

- 金額は **整数の日本円** で保存し、浮動小数点を使わない。
- 日時は DB では UTC、画面では JST で表示する。
- 取引時点のタイトル・説明・送料条件などは `Order` にスナップショットを保持する。
