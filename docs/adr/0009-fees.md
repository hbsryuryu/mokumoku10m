# ADR-0009: 手数料は落札時のみ、落札価格の10%（税込）とする

- 状態: 提案中（手数料体系の方針。税・請求方法は未決）
- 日付: 2026-11-13
- 決定者: TeraoShinji-5（チームでの確認は PR で行う）
- 関連: [ADR-0007](0007-align-with-yahoo-auctions.md)（Yahoo!オークション準拠）、[`open-questions.md`](../product/open-questions.md) #1・#2・#4、[`auction-site-spec.md`](../product/auction-site-spec.md)

## 背景

手数料（マネタイズ）は未決事項 #1 のまま残っていた。ADR-0007 は「オークションのルール」を Yahoo!オークションに合わせる方針だが、手数料は事業判断のため対象外としていた。落札後の取引（`Order`）や出品者に見せる手取り額を設計するには、手数料体系を決める必要がある。

参考として、Yahoo!オークション（個人出品）の料金を確認した（2026-11-13 確認）。

| 項目 | Yahoo!オークション |
|---|---|
| 落札システム利用料 | 落札価格の10%（税込）。出品者が負担し、落札されたときだけかかる |
| 出品システム利用料 | 0円（自動車・バイクなど一部の特定カテゴリを除く） |
| 初期費用・月額 | なし |
| 有料会員による割引 | なし（2024年6月4日以降の落札から、会員・非会員とも一律10%） |
| 落札者の負担 | システム利用料なし |

出典: [ご利用料金 - Yahoo!オークション ご利用ガイド](https://auctions.yahoo.co.jp/guide/m/navi/archives/fee.html)、[特定商取引法に基づく表示](https://auctions.yahoo.co.jp/special/html/p/tokushoho.html)

## 選択肢

1. **落札時のみの定率（Yahoo!オークションと同じ）** — 出品の敷居が低く、利用者に馴染みがある / 落札されないと収益にならない
2. 出品時にも課金する — 冷やかしの出品が減る / 出品の敷居が上がり、MVP で検証したい出品数が伸びにくい
3. 価格帯で料率を変える、定額にする — 高額品の不公平感を調整できる / 計算・説明が複雑になる

## 決定

選択肢1を採用する。

- **落札手数料**: 落札価格の **10%（税込）**。**出品者**が負担する。
- **出品手数料**: **無料**。初期費用・月額費用もない。
- **落札者**: 手数料を負担しない（商品代金と送料のみ）。
- **料率**: 落札価格によらない**定率**。価格帯別の料率・最低額・上限額、カテゴリ別の定額は設けない。会員種別による割引もない。
- **端数処理**: 円未満は**切り捨て**る。浮動小数点を使わず、整数演算 `手数料 = 落札価格 × 10 // 100` で計算する。
  - 例: 落札価格1,000円 → 100円、1,005円 → 100円、999円 → 99円、9円 → 0円（落札価格が10円未満なら手数料は0円）
- **課金対象**: `Order` が作成された落札だけ。通常の終了・即決・早期終了による落札はすべて対象とする。次の場合は手数料が発生しない。
  - 入札なしで終了した場合
  - 出品者が取り下げた場合（受付済み入札がない場合のみ可能、ADR-0004）
  - 運営が停止・キャンセルし、`Order` を作成しなかった場合

## 理由

- ADR-0007 で参考サービスを Yahoo!オークションに決めており、手数料もそろえると利用者の想定とずれない。
- 出品無料にすると出品の敷居が下がり、MVP で確かめたい「出品から公開までの完了率」を測りやすい。
- 定率1種類なら計算・表示・テストが単純になる。
- 切り捨ては出品者に不利にならない方向の丸めで、整数演算だけで実装できる（金額は整数の円で扱う。AGENTS.md 4章）。

## 影響

- **資金は動かさない**: MVP は本番の資金移動を行わない（AGENTS.md 2.2）。手数料は**計算して表示するところまで**とし、実際の徴収は未決 #2 が決まるまで行わない。
- **データモデル**: `Order` に、落札時点の手数料率と手数料額（整数 JPY、税込）をスナップショットとして持たせる。後から料率を変えても、過去の取引の金額が変わらないようにする。
- **画面**: 出品フォームと出品管理に「落札された場合は落札価格の10%（税込）がかかる」ことを明示する。取引詳細に、出品者向けの手数料額と手取り見込み額を表示する（AGENTS.md 6章「価格を誤認させない」）。
- **テスト**: 手数料計算のユニットテスト（切り捨ての境界: 9円・10円・999円・1,000円・1,005円、上限の1,000万円）と、落札なし・取り下げ・運営キャンセルで手数料が発生しないことを確認する。
- **規約**: 公開前に、利用規約と特定商取引法に基づく表示に手数料を記載する（[`production-readiness.md`](../runbooks/production-readiness.md)）。
