# ローカルプロトタイプ運用手順

## 前提

静的ファイルのみで動作します。Node.jsの依存インストール、DB、環境変数、秘密情報は不要です。

## 起動

リポジトリのルートでPowerShellを開き、次を実行します。

```powershell
py -m http.server 8000
```

ブラウザで `http://localhost:8000` を開きます。停止するにはサーバーを起動した端末で `Ctrl+C` を押します。Pythonがない場合は `index.html` を直接ブラウザで開けますが、一部ブラウザの保存領域の扱いはHTTP配信と異なることがあります。

## デモ確認

1. 初期一覧、カテゴリ切替、キーワード検索、並び替えを確認する。
2. 商品カードを開き、状態、配送条件、詳細説明を確認する。
3. ウォッチを追加し、再読み込み後も状態が残ることを確認する。
4. 商品詳細から最低入札額以上の整数円を入札し、価格・履歴が更新されることを確認する。
5. 出品フォームで必須項目を入力し、一覧に追加されることを確認する。
6. 不正な価格、空欄、HTTP画像URLが拒否されることを確認する。

すべてブラウザ内のデモです。別ブラウザ・端末・ユーザーには同期されません。決済や実際の注文はありません。

## デモデータのリセット

ブラウザのサイト設定から `localhost` のサイトデータを消去してください。開発者ツールを使う場合は、Application/Storage の Local Storage から `meguru:` で始まるキーを削除します。保存対象は `meguru:listings`、`meguru:watched`、`meguru:bids` です。削除すると出品、ウォッチ、デモ入札履歴は復元できません。

## トラブル対応

- 画面が更新されない: ページを再読み込みし、`index.html`、`styles.css`、`app.js` が同じディレクトリにあることを確認する。
- 出品が見えない: カテゴリ・検索条件を解除し、ブラウザのサイトデータ保存が有効か確認する。
- 画像が表示されない: HTTPS URLか、URLがブラウザから取得可能か確認する。外部ホストの制限で読み込みに失敗する場合がある。
- JavaScriptエラー: 開発者ツールのConsoleでエラーを確認する。localStorageの不正データを消して再読み込みする。
- 保存領域が使えない: プライベートブラウズや容量制限の可能性がある。通常ブラウズで再確認する。
