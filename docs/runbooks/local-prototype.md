# ローカル画面の確認手順

画面はバックエンドと同じオリジンで動作します。リポジトリ直下で `docker compose up -d --build` を実行し、http://localhost:8000/ を開いてください。詳細は [バックエンド起動手順](local-backend.md) と [画面の操作方法](../../README.md#フロント画面の起動と操作) を参照してください。

## 確認すること

1. 開発用ログインを行い、画面の表示名が変わる。
2. 出品を下書き保存し、再読み込み後に「自分の出品」から取得できる。
3. 下書きの編集・公開を行い、ログアウト後も公開一覧・検索・カテゴリ・詳細で閲覧できる。
4. 取り下げ後に公開一覧から消える。
5. 通信失敗でエラーと再読み込み操作が表示される。
6. 入札・ウォッチを実行済みと表示しない。

`python -m http.server` やHTMLファイルの直接表示ではAPI接続はできません。旧 `meguru:` のブラウザ保存データは参照・移行・削除しません。DockerのDBをリセットするときはデータが消えるため、バックエンド手順に従ってください。
