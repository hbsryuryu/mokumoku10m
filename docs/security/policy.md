# セキュリティ・プライバシー方針

> 出典: AGENTS.md 7章。

- 更新系 API では認証・認可とリソース所有者チェックを実施する。
- SQL インジェクション、XSS、CSRF、SSRF、IDOR、認証情報漏えいを防ぐ。
- ログイン、出品、入札、通報等にレート制限を設ける。
- メール認証、セッション保護、重要操作の再認証を検討する。
- 画像は形式・サイズ・個数を制限し、拡張子だけを信用しない。EXIF 位置情報の除去を検討する。
- 秘密情報は環境変数／Secrets Manager で管理し、Git にコミットしない。
- ログに個人情報・認証トークン・決済情報を不要に記録しない。
- 不自然な入札、吊り上げ行為、複数アカウント悪用を調査できる記録を設計する。
- 個人情報の保存期間、削除請求、アクセス制限、バックアップ復元を運用設計に含める。
- 利用規約、プライバシーポリシー、特定商取引法表示、古物営業・資金移動等の法的論点は専門家と確認する。
