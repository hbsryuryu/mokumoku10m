# めぐる市 — オークションMVPプロトタイプ

個人間オークションの主要な利用フローを確認する、依存パッケージ不要の静的フロントエンドです。日本語・モバイル対応の画面から、サンプル商品の検索、カテゴリ絞り込み、並び替え、詳細閲覧、ウォッチ、デモ入札、出品登録を試せます。

## 起動方法

`index.html` をブラウザで開くか、リポジトリのルートで静的ファイルサーバーを起動してください。

```powershell
py -m http.server 8000
```

ブラウザで `http://localhost:8000` を開きます。商品画像URLにはHTTPSのURLを指定してください。

## 実装範囲と制約

- 商品一覧、キーワード検索、カテゴリ、並び替え、商品詳細、ウォッチ、デモ入札、ブラウザ内の出品保存を実装しています。
- 出品、ウォッチ、入札は `localStorage` に保存され、同一ブラウザ内でのみ保持されます。ログインフォームはデモ案内のみで、入力情報は保存しません。
- 入札処理・オークション終了・落札・取引・通知はサーバーに接続されていません。複数ユーザー間の同期、認証、メール確認、画像アップロード、管理機能、決済はありません。実際の取引や決済は発生しません。
- サンプル出品は画面確認用の架空データです。外部画像は使わず、CSSの図形とアイコンで表示します。
- このプロトタイプを本番取引に使用しないでください。サーバー基準の時刻、DBトランザクションによる入札直列化、冪等性、終了確定、権限検証を備えたAPIとDBが別途必要です。

## 次の実装段階

MVPの本番相当化には、ADRに基づく認証基盤・DB・APIの選定、メール認証、出品画像の検査付きアップロード、入札の原子性と競合テスト、終了処理と冪等な取引作成、通知Outbox、通報・運営監査、運用監視・バックアップ、法務・決済・本人確認設計が必要です。決済を伴う本番公開は、これらの運用準備が整うまで行いません。
